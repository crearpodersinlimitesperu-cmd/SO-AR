# Requisitos Funcionales

1. **Consulta de Nodus**: Recuperación precisa de KPIs operativos y de gestión.
2. **Consulta de Notebook**: Recuperación de políticas y procedimientos.
3. **Relación de Fuentes**: Capacidad de cruzar una política (Notebook) con un dato actual (Nodus).
4. **Historial de Conversaciones**: Los chats deben persistir en Firestore.
5. **Detección de Vacíos**: Informar claramente cuando la información no existe.
